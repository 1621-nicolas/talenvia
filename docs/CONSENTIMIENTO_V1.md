# Talenvía: consentimiento para enviar CV — v1

Identificador interno: **talenvia-cv-v1**.

En el formulario de postulación, la persona autoriza expresamente que la empresa destinataria de una oferta reciba:

- La versión de CV en PDF vinculada a esa postulación.
- Su dirección de correo electrónico.
- Su teléfono, solo si lo proporcionó voluntariamente.

Finalidad: permitir que esa empresa se comunique con la persona postulante acerca de la oferta específica. No se comparten las preferencias privadas de apoyos ni información médica. El consentimiento se solicita para cada nueva postulación mediante una casilla no marcada inicialmente.

El registro guarda \`consentimiento_fecha\`, \`consentimiento_version\`, la versión del CV y la empresa/oferta receptora. Los registros anteriores a esta versión se identifican como \`historico-sin-evidencia\`: no se inventa una fecha ni se supone la versión aceptada.

Este texto describe un requisito funcional del prototipo y no sustituye una política integral de protección de datos ni asesoría jurídica.
